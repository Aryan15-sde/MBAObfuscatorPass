# MBAObfuscatorPass

An out-of-tree **LLVM 21 New Pass Manager** transformation pass that protects C/C++ programs using **2-round Mixed Boolean-Arithmetic (MBA) obfuscation**.

## What Is MBA Obfuscation?

Standard compiler optimizations (`-O2`, `-O3`) make code clean, which also makes it easy for reverse-engineers to read in decompilers. **MBA obfuscation** replaces simple math and logic instructions with equivalent, tangled combinations of bitwise and arithmetic operations—preserving the exact runtime output while hiding program logic.

## Obfuscated Operations (2 Cascading Rounds)

| Original Operation | LLVM IR | Obfuscated Identity |
| :--- | :--- | :--- |
| **Addition** (`a + b`) | `add` | `(a ^ b) + ((a & b) << 1)` |
| **Subtraction** (`a - b`) | `sub` | `(a ^ b) - ((~a & b) << 1)` |
| **Bitwise XOR** (`a ^ b`) | `xor` | `(a | b) - (a & b)` |
| **Bitwise AND** (`a & b`) | `and` | `(a + b) - (a | b)` |
| **Bitwise OR** (`a | b`) | `or` | `(a ^ b) + (a & b)` |

Because the pass runs **2 cascading rounds**, Round 2 scrambles the instructions generated by Round 1—expanding a single instruction into a ~10–12 instruction maze.

## Quick Demo (1 Command)

    chmod +x run.sh && ./run.sh

This automatically builds the pass, compiles `tests/test.c` to LLVM IR, runs `mba-obfuscator`, prints the `diff`, and executes the obfuscated binary.

## Manual Build & Run

    cmake -B build -G Ninja && cmake --build build
    clang -S -emit-llvm tests/test.c -o tests/test.ll
    opt -load-pass-plugin ./build/MBAObfuscatorPass.so -passes="mba-obfuscator" -S tests/test.ll -o tests/test_obfuscated.ll
    diff tests/test.ll tests/test_obfuscated.ll
    clang tests/test_obfuscated.ll -o tests/test_obfuscated && ./tests/test_obfuscated

## Project Structure

* `MBAObfuscatorPass.cpp` — LLVM New Pass Manager plugin (`mba-obfuscator`)
* `CMakeLists.txt` — Out-of-tree CMake build configuration
* `tests/test.c` — Interactive C test program covering all 5 operations
* `run.sh` — One-command build, diff, and execution script
